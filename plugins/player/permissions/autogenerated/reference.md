## Default Permission

Allows the webview to drive the native video player

#### This default permission set includes the following:

- `allow-get-state`
- `allow-pick-videos`
- `allow-play`
- `allow-next`
- `allow-pause`
- `allow-resume`
- `allow-stop`
- `allow-remove`
- `allow-set-options`
- `allow-set-system-overlays`
- `allow-register-listener`
- `allow-remove-listener`
